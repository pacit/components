Get started

Standalone components on Angular 22 — zoneless, signal forms, SSR-ready. Three steps from an empty app to a validated field.

1 · Install

No zone.js anywhere in the tree — the package refuses it by gate, not by convention.

2 · Provide

The library reads one optional config for defaults; the application stays the owner of policy — locale, texts, theme.

3 · A first form

Signal forms end to end: the model is a signal, the schema is a function, the field wrapper wires the label, hint and error lines.

Server-side rendering

Every component hydrates cleanly — the sandbox suite measures it per view, in three engines. Add provideClientHydration() and prerender or SSR as your host prefers; this documentation site is itself prerendered from the same package.
