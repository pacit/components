Density

The second axis, and it is an attribute: data-pct-density="compact" on any element re-points the metric tokens under it — the shared control axis and the space scale — so everything below gets shorter and tighter. Not one component reads the attribute; the cascade does the work, exactly as it does for data-theme. The two axes are independent: the attribute below sits inside the card's own theme scope and moves no colour.
