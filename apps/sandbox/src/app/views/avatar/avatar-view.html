Avatar

The picture beside a name — and never the name itself: the host is aria-hidden outright, because where an avatar stands the name is already text a reader says. What the component owns is the fallback chain — image, initials, silhouette, exactly one standing — and initials that are graphemes, so an emoji family or a Devanagari matra never comes back as half a character.
