<!-- The icon is an image when it is named and decoration when it is not, as `pct-icon` is,
     and the bar a control no user lands on — inside a role whose children are presentational
     neither is a control of its own, whatever role an expression gives the icon: the button
     around both is still one control. The role an expression decides on the button sits on a
     native control, which is the control a user lands on whatever role it wears. Drawn on a
     stop, the toggle is a `role="button"` written onto a `<span>` a `tabindex` makes one: the
     written role makes its children presentational as the tag's own does, so the same icon is
     part of it there too. The frame is a stop around the control and takes no name, so point 4
     asks nothing of it. A toggle that leads somewhere is a link: an `<a>` with an address
     takes the name by the platform's own role, where axe's element table read alone would
     forbid one on the tag. A link's children are not presentational, so its icon cannot take
     the role an expression decides — that could be any control, and a control inside the
     link is one the reader meets on its own. It is drawn only when it is named, with the role
     written: an image is a structure, named and never operated, and no control there either.
     A picture given instead is a native `<img>`, no role written: an image named by its `alt`,
     or decoration when the `alt` is empty — a structure either way, read off the tag as a
     written role is, and no control inside the link. -->
