     `FALSE`, at `Undefined` and with no value; a class and an animation named `inert`, which
     write no attribute; an `inert` on an SVG group, which is HTML's attribute alone. The hint
     under an `aria-hidden` is still the control's description in both. Nothing sets a part's
     live region either (measured on 2026-10-27): an `aria-live` above the error, which Firefox

     left empty, which is none to either engine, or named by a class binding; the three at their
     worst above the hint, which is no live region, and on an element before the line. -->
