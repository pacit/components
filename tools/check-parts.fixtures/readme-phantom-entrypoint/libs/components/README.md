# @pacit/components

The npm page with a row the manifest does not back — a promise a consumer's import turns
into a resolution error.

## Entrypoints

| entrypoint                 | what is in it            |
| -------------------------- | ------------------------ |
| `@pacit/components`        | configuration            |
| `@pacit/components/widget` | `PctWidget`, `PctMarker` |
| `@pacit/components/ghost`  | nothing — no manifest    |
