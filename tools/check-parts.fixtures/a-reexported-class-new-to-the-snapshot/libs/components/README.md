# @pacit/components

The reference package's npm page. The entrypoint table below is what point 7 reads: a row
per entrypoint of the packed manifest, and no row beyond it.

## Entrypoints

| entrypoint                 | what is in it                                               |
| -------------------------- | ----------------------------------------------------------- |
| `@pacit/components`        | configuration                                               |
| `@pacit/components/widget` | `PctWidget` (also as `PctGadget`), `PctMarker` as `PctMark` |
| `@pacit/components/wrap`   | a class of `./widget`                                       |
